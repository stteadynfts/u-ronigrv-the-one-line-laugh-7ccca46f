# The One-Line Laugh

Entry for the Make Fun competition `u-ronigrv-the-one-line-laugh-7ccca46f`.

`main.py` (Python 3.13, standard library only) writes one original funny
line — a single sentence, under 200 characters — to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

See `DOSSIER.md` for the brainstorm, the field study, and why the final
line was chosen.
